=======================================================
项目结构
=======================================================
iptv-test/
├── config/                # 配置文件夹
│   ├── input.txt          # 待检测直播源地址
│   ├── demo.txt           # 输出频道模板
│   ├── alias.txt          # 频道别名映射（无需区分大小写，如CCTV等同于cctv）
│   └── settings.inf       # 运行参数配置
├── output/                # 输出文件夹
│   ├── lives.txt          # 最终可用直播源（影视仓专用）
│   └── unused.txt         # 有效但未使用的高清源
├── bin/               
│   ├── utils.py           # 工具函数（读取、请求、解码）
│   ├── filter.py          # 核心筛选逻辑（验证、分辨率、匹配）
│   ├── core.py            # 核心调度
│   └── ffprobe.exe        # 自行下载放入（下载地址见下文）
├── main.py                # 主程序入口
└── README.md              # 说明文档

=======================================================
IPTV 直播源筛选工具 - 配置文件说明
=======================================================

1. input.txt
   作用：存放直播源地址，无效会自动加 # 注释（支持本地/网络txt/m3u）
   格式：一行一个地址
   示例：
   https://example.com/live.txt
   E:/iptv/source.m3u

2. demo.txt
   作用：输出频道模板（顺序/分类/频道名）
   程序会严格按照这个文件的结构输出结果
   示例：
   📺央视频道,#genre#
   CCTV-1
   CCTV-2

3. alias.txt
   作用：统一不同来源的混乱频道名
   格式：标准名称,[别名1,别名2,别名3...]
   例：CCTV-1,[CCTV1,CCTV-01高清,中央1台]

4. output/result.txt
   作用：最终筛选好的高清直播源（自动生成）

5. output/unused.txt 
   作用：有效但不在模板中的高清源
=======================================================
